## 🚀 Featured Projects

### 🎓 RAG Based AI Teaching Assistant

<img align="right" src="https://github-readme-stats.vercel.app/api/pin/?username=sanketchothe&repo=rag-ai-teaching-assistant&theme=nord&border_color=7dd3fc&title_color=7dd3fc&text_color=c9d1d9&bg_color=0d1117" alt="RAG AI Teaching Assistant pin"/>

A Retrieval-Augmented Generation (RAG) based AI Teaching Assistant that transcribes lecture videos, chunks and embeds text, performs semantic search, and uses an LLM to generate accurate, context-aware answers from uploaded lecture content.

| Layer | Technology |
|---|---|
| Language | Python |
| Speech-to-Text | Whisper |
| Orchestration | LangChain |
| NLP | Natural Language Processing |
| Retrieval | Vector Database |
| LLM Runtime | Ollama |

🔗 Code: [github.com/sanketchothe/rag-ai-teaching-assistant](https://github.com/sanketchothe/rag-ai-teaching-assistant)
